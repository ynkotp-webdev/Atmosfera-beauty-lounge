# Atmosfera: концепт-сайт салона

Концепт для портфолио YonkaAgency: салон «Атмосфера», Львов, две точки. Astro + Tailwind 4, статика.
Сайт на украинском, общение с Остапом на русском. Запуск dev-сервера описан в `AGENTS.md`.
Деплой: push в `main` → GitHub Actions → https://ynkotp-webdev.github.io/Atmosfera-beauty-lounge/. Сайт в подпапке
(`base` в `astro.config.mjs`), поэтому внутренние ссылки только через `to()` из `src/data/salon.ts`. Из `content/`
в git попадает лишь `bloknot/services.json`, его читает сборка.
Задание на сборку сайта лежит в `BRIEF.md`: решения Остапа, страницы, фото, единственный стоп.

## Дизайн и вёрстка

Главная цель проекта: сайт не должен выглядеть собранным нейросетью. Поэтому бриф и анти-слоп правила
подгружаются в каждую сессию:

@PRODUCT.md
@design-anti-slop/README.md

Дальше по этапам, без пропусков:

1. **До выбора композиции, цвета и шрифтов** прочитай `design-anti-slop/rules.md` целиком.
2. **Перед показом результата** пройди `design-anti-slop/checklist.md` по скриншотам 1440 и 390, а не по коду.
   Приложи итог: что прошло, что нет, что оставлено намеренно и почему.

Это действует и при работе через скиллы (impeccable, beauty-redesign и любые другие): их дефолты эти правила
не отменяют.

**При конфликте:** прямые слова Остапа, затем `PRODUCT.md`, затем `design-anti-slop/`, затем дефолты скиллов.

`PRODUCT.md` это бриф проекта. Переписывать его только с согласия Остапа.
